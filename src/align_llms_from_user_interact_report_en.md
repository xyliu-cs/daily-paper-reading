## 1. Background and Problem

Large language model inference now dominates compute consumption, with models serving massive volumes of user queries daily, yet the information revealed through these multi-turn interactions is typically discarded. Follow-up user messages—such as error reports, format corrections, or style requests—contain rich implicit alignment signals, but existing methods (RLHF, DPO) cannot leverage raw conversational data as they require explicit labels, reward models, or curated preference pairs. The central question of this paper is: *Can we train language models directly from multi-turn user interactions in a simple, principled, and scalable manner?*

### 1.1 Core Hypothesis

The paper's key observation is that language models already possess the in-context ability to revise their behavior upon seeing a user's follow-up message. This suggests that the model's in-context learning capability can serve as a lever: by conditioning the model on the follow-up and comparing the resulting token distribution with the original policy, one obtains a principled credit-assignment signal that can be distilled into model weights without any auxiliary mechanisms.

## 2. Method

![Figure 1: Overview of SDPO — Direct Learning from User Interactions via Self-Distillation](align_llms_from_user_interact_fig/align_llms_from_user_interact-Figure1-1.png)

SDPO formalizes each user interaction as a triple $(x, y, o)$: conversation history $x$, model response $y$, and user follow-up $o$. The method constructs a **hindsight policy** $\pi_\theta(\cdot \mid x, o)$ by appending the user's follow-up message to the prompt (via a dedicated chat template, Table 1) and re-querying the same model, which reflects how the model would respond if it already knew the follow-up information. The token-level advantage $A_i(x,y,o) := \log \pi_\theta(y_i \mid x, o, y_{<i}) - \log \pi_\theta(y_i \mid x, y_{<i})$ quantifies how each token's likelihood shifts in hindsight: tokens with positive advantages are reinforced and those with negative advantages are suppressed. The training objective minimizes the per-token reverse KL divergence between the current policy and the stop-gradient hindsight policy: $\mathcal{L}_{\text{SDPO}}(\theta) = \sum_i \mathrm{KL}(\pi_\theta(\cdot \mid x, y_{<i}) \,\|\, \bar{\pi}_\theta(\cdot \mid x, o, y_{<i}))$. For offline logged interactions (where completions were generated by a different model), an off-policy surrogate objective is optimized directly over the interaction tuples without requiring access to the behavioral policy's probabilities. Theoretically (Proposition 3.1), under idealized assumptions on user behavior and model conditioning, the sequence-level self-distillation advantage equals the user's latent reward minus a normalization term, meaning SDPO implicitly maximizes the interacting user's latent reward function.

## 4. Limitations and Future Work

### 4.1 Original Description

The paper highlights important safety and ethical considerations in its Discussion section: user follow-ups may implicitly reward evasive, misleading, or policy-violating responses, and continual personalization without guardrails poses a risk of adversarial steering by malicious users over time. While SDPO naturally suppresses updates from irrelevant interactions, it does not by itself distinguish benign from adversarial learning signals. The authors note that the hindsight prompt may offer a principled location at which to inject safety principles, and that any deployment of interaction-based learning must be accompanied by appropriate transparency, consent, and governance mechanisms.

### 4.2 Model Summary

SDPO's primary limitations are: (1) the quality of the hindsight signal depends on the model's in-context learning capability—weaker or less instruction-tuned models may produce noisier self-distillation targets, as evidenced by the mild degradation of Qwen3-4B on math/coding tasks; (2) the method only exploits the immediate next user message, leaving longer-horizon multi-turn feedback patterns unexplored; (3) the off-policy surrogate objective introduces gradient bias, and principled off-policy correction remains an open problem. Promising future directions include extending SDPO to multi-hop signals across longer conversation windows, integrating safety-aware hindsight prompts for adversarial robustness, and studying distribution shift under continuous deployment.
