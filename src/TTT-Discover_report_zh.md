## 1. 研究背景和问题

科学发现问题（Discovery Problem）要求 AI 产出超越人类已有知识边界的解决方案，这远比标准的测试时推理更具挑战性。现有的测试时扩展方法（如 AlphaEvolve）通过对冻结的 LLM 进行搜索式提示来生成候选解，但模型本身并不从经验中学习——类似于一个始终无法内化新概念的学生。然而，AI 历史上学习（learning）在围棋和蛋白质折叠等困难问题上已多次超越搜索（search）。本文提出的核心问题是：**能否在测试时对 LLM 进行强化学习训练，使其在特定科学问题上持续改进，从而实现真正的发现？**

### 1.1 核心假设

本文认为，发现问题与标准 RL 存在两个关键差异：（1）策略只需解决当前这一个问题，而非泛化到其他问题；（2）我们只需要一个最佳解，而非最大化平均奖励。因此，学习目标和搜索子程序都应强烈偏向最有前景的解决方案。

---

## 2. 方法

TTT-Discover 将每个科学问题建模为一个马尔可夫决策过程（MDP）环境，其中状态（state）是候选解（如核代码、数学构造），动作（action）是 LLM 生成的思考链和代码，奖励（reward）由问题本身的评估函数给出（如核运行时间的倒数）。方法的核心由两个组件构成：

**熵目标函数（Entropic Objective）**：不同于标准 RL 优化期望奖励，TTT-Discover 使用参数化的熵目标 $J_{\beta(s)}$，其中 $\beta$ 自适应调节，使优化更偏向最大奖励的动作而非平均表现。当 $\beta \to \infty$ 时，目标趋近于最大值，这正是发现问题所需要的。自适应 $\beta$ 通过约束 KL 散度来避免训练不稳定。

**PUCT 状态复用（PUCT Reuse）**：借鉴蒙特卡洛树搜索中的 PUCT 规则，对缓冲区中的历史状态进行评分和选择，作为下一轮生成的初始状态。评分使用子状态的最大奖励（而非均值）作为 Q 值，高奖励状态有更高的先验概率，同时探索奖励保证欠访问的状态不被忽略。这一机制有效延长了搜索的有效视野（effective horizon），使更复杂的解可以逐步涌现。

实现上，TTT-Discover 使用 gpt-oss-120b 模型在 Tinker 平台上运行 50 个训练步，每步生成 512 个 rollout（8 组 × 64），使用 LoRA（rank 32）进行参数高效微调，单次运行成本约 $500。

## 3. 实验

### 3.1 实验设置

| 维度 | 名称 | 数量 |
|---|---|---|
| **模型** | gpt-oss-120b, Qwen3-8B | 2 |
| **训练** | 每个问题定义的环境（单问题 RL） | 每步 512 rollouts × 50 步 = 25,600 |
| **评测** | Erdős 最小重叠问题、自相关不等式（AC1/AC2）、圆填充、TriMul 核竞赛（A100/H100/B200/MI300X）、MLA-Decode、AtCoder AHC039/AHC058、单细胞 RNA-seq 去噪 | 10+ 个任务 |
| **指标** | 上界/下界值、核运行时间 (µs)、竞赛得分、MSE、Poisson NLL | 5+ |

## 4. 局限性与未来工作

### 4.1 原文描述

论文明确指出，TTT-Discover 当前形式只能应用于具有**连续奖励**的问题。最重要的未来方向是将测试时训练扩展到具有稀疏或二值奖励的问题，以及不可验证领域（non-verifiable domains）的问题。此外，在单细胞分析应用中，作者也强调 benchmark 指标的提升不一定保证生物学有效性。

### 4.2 模型总结

TTT-Discover 的核心局限在于其对连续可验证奖励信号的强依赖——这排除了大量实际科学问题（如定理证明、药物设计中的离散判定问题）。此外，方法的成本虽相对低廉（约 $500/问题），但仍需要可扩展的 RL 基础设施和足够的 GPU 算力，限制了更广泛的研究者复现。环境设计（奖励函数、状态定义、验证逻辑）高度依赖领域专业知识，这意味着方法的可迁移性取决于能否为新领域设计合适的 MDP 环境。未来，结合过程奖励模型（process reward models）或 LLM-as-judge 技术来处理稀疏/不可验证奖励，以及探索多问题间的知识迁移（而非当前的单问题隔离训练），可能是有价值的研究方向。（由 Claude Opus 4.6 模型生成）
